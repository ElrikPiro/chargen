# E3 database compatibility fixture

The integration fixture in `crates/chargen-store/tests/fixtures/e3-b0.sql` is a
read-only SQLite dump of `target/validation/e3-b0.sqlite3`, produced by engine
commit `5b11a50` before E4. The captured source database SHA-256 is
`64dc2a40637693fe9b3fb2e33e8762a6955ce4c139257590ea3981a3ff7e8d58`. The
fixture records this provenance in its header. Its expected annual hashes were
read directly from that source database's `annual_commits` table; they are not
generated by the E4 implementation.

`crates/chargen-store/tests/e3_compatibility.rs` checks the ten stored
state/event/commit hash triples, exact E3 replay state and event payloads, and
advancement from the stored year-9 head to year 10. It also checks the
materialized database bytes and all original hash triples after read/replay,
which catches a load path that rewrites legacy history. The test materializes
the SQL fixture in a temporary directory; it never opens the validation source
database for writing.
