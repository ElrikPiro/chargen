# Código Python histórico

El 12 de octubre de 2026 se trasladaron aquí el paquete, pruebas, ejemplos, PoC, configuración JSON, utilidades, notebook y documentación y distribuciones de la implementación Python. Se preservaron los contenidos de los cambios locales, sin restaurar ni sobrescribir el índice Git.

`source-inventory.json` registra la ruta original y SHA-256 de 60 archivos fuente y recursos. Los entornos virtuales y caches no forman parte del inventario; no se usan en la aplicación Rust. Las rutas relativas del código histórico se mantienen bajo este directorio. Para consultar los comandos anteriores, ver `README.md` y `DOCUMENTATION.md` de esta carpeta.

Este archivo es de consulta, sin migración automática de mundos ni uso como motor de producción. La licencia sigue en `../LICENSE`.
