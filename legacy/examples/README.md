# Usage examples

This folder contains runnable examples for common workflows.

## Run an example

From the repository root:

```bash
python3 examples/basic_character.py
```

## Available examples

- `examples/basic_character.py`: create a character with default storage (`json/`).
- `examples/configurable_character.py`: use an isolated JSON root via `JsonStore`.
- `examples/render_markdown.py`: render a markdown sheet from a saved character.
- `examples/casamentera_simulation.py`: run one matchmaking iteration.
